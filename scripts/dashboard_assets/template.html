Módulo de verificação de jogador

Para descobrir se um jogador novo entraria neste time — e por quê — rode o script abaixo passando o link do efhub.com dele.

# exemplo
python3 scripts/check_player.py https://efhub.com/players/<id>

Para atualizar o time inteiro depois de mexer no elenco: edite players.txt, rode fetch_players.py e depois select_team.py.

Gerado a partir de data/best_team.json · atributos e Community Tier Ranking extraídos do efhub.com. *Overmax = projeção estimada de treino (não é dado oficial). Análise Ofensiva/Defensiva é uma aproximação a partir dos atributos, não um dado do jogo.
